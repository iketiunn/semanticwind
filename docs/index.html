A deliberate boundary

One baseline. Three honest layers.

Use the smallest layer that can express the design choice without hiding what it means.

  1. 01

    Semanticwind

    Typography, forms, tables, media, and native interaction get a useful default.

  2. 02

    Tailwind utilities

    Add layout, responsive behavior, or a local visual exception where it happens.

  3. 03

    Your components

    Give repeated UI and product concepts their own explicit component meaning.

Would this style make sense for almost every correct use of this element?

If yes, it may belong in Semanticwind. If not, reach for a utility or component.
